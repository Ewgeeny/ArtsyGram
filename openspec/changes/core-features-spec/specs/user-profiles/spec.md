## ADDED Requirements

### Requirement: View user profile
The system SHALL display a user's profile with their posts.

#### Scenario: Profile view
- **WHEN** a user visits another user's profile
- **THEN** the profile shows the user's posts sorted by newest first

### Requirement: Own profile indicator
The system SHALL indicate when viewing your own profile.

#### Scenario: Own profile detection
- **WHEN** a user views their own profile
- **THEN** additional options like edit/delete are available
