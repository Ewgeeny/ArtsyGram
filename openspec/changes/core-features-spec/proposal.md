## Why

The ArtsyGram project needs a formal specification of its core features for the Bachelor Web Engineering course. This spec documents the implemented functionality as a baseline for future development and evaluation.

## What Changes

- Creates a comprehensive specification of existing core features
- Documents user authentication, post management, search/filtering, profiles, and favorites
- Establishes requirements baseline for the application

## Capabilities

### New Capabilities

- `user-auth`: User registration, login, logout, and session management
- `post-crud`: Creating, editing, and deleting image posts
- `categories-tags`: Organizing posts with categories and tags
- `search-filter`: Finding posts by search term, category, and tags
- `user-profiles`: Viewing user profiles and their posts
- `favorites`: Private list of saved posts per user

### Modified Capabilities

None - this is initial specification of existing features.

## Impact

- Affected code: All core app functionality (models, views, templates)
- Documentation: Provides formal requirements for evaluation
- No code changes required - specification only
